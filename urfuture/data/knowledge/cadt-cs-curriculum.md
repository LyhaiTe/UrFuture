The Cooperation Committee for Cambodia's Academy of Digital Technology (CADT)
Bachelor of Computer Science program includes a core software-engineering
track covering: Introduction to Programming (Python), Data Structures &
Algorithms, Object-Oriented Programming (Java), Web Application Development
(HTML/CSS/JavaScript, then a modern frontend framework), Database Systems
(relational modeling and SQL), Software Engineering Principles (version
control, testing, agile process), and a capstone Software Project course in
the final year requiring a deployed, team-built application.

Students targeting frontend development roles are advised to pair the Web
Application Development course with the optional Human-Computer Interaction
elective and to build a portfolio project during the Software Project
capstone that demonstrates component-based UI architecture and API
integration, since employer surveys (see NEA_SURVEY_2023) rank hands-on
project experience above GPA for entry-level hiring.
