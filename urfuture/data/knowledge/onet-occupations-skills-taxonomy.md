The Occupational Information Network (O*NET) Content Model provides the standard occupational classification system and skills taxonomy referenced by the UrFuture Career Advisor. The following high-priority career paths are aligned with Cambodia's digital economy development priorities:

### 1. Software Engineer (O*NET-SOC 15-1252.00)
- **Role Summary**: Design, build, and maintain software applications and systems.
- **Core O*NET Skills**:
  - `2.B.3.f` Programming Fundamentals (Importance: 92/100) — Writing robust, modular computer programs in languages such as Python, TypeScript, and Go.
  - `2.B.3.g` Data Structures & Algorithms (Importance: 88/100) — Analyzing algorithmic time and space complexity, hash structures, trees, and graphs.
  - `2.B.3.a` Systems Analysis & Architecture (Importance: 82/100) — Determining how software modules interact and designing scalable multi-tier architectures.
  - `2.B.3.d` Software Testing & Quality Assurance (Importance: 80/100) — Designing unit, integration, and end-to-end automated test suites.
- **Cambodia Context**: High demand in Phnom Penh's commercial banking, fintech, and digital transformation consulting firms. Typical entry education: Year 2-3 University level.

### 2. Frontend Developer (O*NET-SOC 15-1254.00)
- **Role Summary**: Design and develop responsive web interfaces and user-facing web applications.
- **Core O*NET Skills**:
  - `2.B.3.f` Web Programming & UI Engineering (Importance: 90/100) — Proficiency in modern reactive frameworks (React, Next.js, Vue).
  - `2.C.3.b` User Experience & Interface Design (Importance: 85/100) — Responsive layouts, accessibility standards (WCAG), and design system implementation.
  - `2.B.3.b` Client-Server API Integration (Importance: 82/100) — Handling state management, RESTful endpoints, and GraphQL queries.

### 3. Data Engineer (O*NET-SOC 15-2051.00)
- **Role Summary**: Build, maintain, and optimize scalable data architectures and pipelines.
- **Core O*NET Skills**:
  - `2.C.3.a` Database Management & SQL (Importance: 92/100) — Relational schema design, query plan profiling, indexing, and NoSQL databases.
  - `2.B.3.g` Data Pipeline & ETL Engineering (Importance: 90/100) — Designing robust data transformation jobs with tools like Apache Spark, Airflow, or Kafka.
  - `2.B.3.b` Cloud Infrastructure & Distributed Systems (Importance: 85/100) — Managing distributed database storage and object repositories.

### 4. Cloud & DevOps Engineer (O*NET-SOC 15-1241.00)
- **Role Summary**: Configure and maintain cloud infrastructure, deployment pipelines, and operational reliability.
- **Core O*NET Skills**:
  - `2.C.3.a` Cloud Infrastructure & Virtualization (Importance: 94/100) — Cloud hosting services (AWS, GCP, Azure), virtual networks, and container engines (Docker).
  - `2.B.3.b` Continuous Integration & Deployment (CI/CD) (Importance: 90/100) — Automated GitHub Actions workflows, infrastructure-as-code, and release management.

### 5. Cybersecurity Analyst (O*NET-SOC 15-1212.00)
- **Role Summary**: Implement and monitor security controls to defend networks, APIs, and confidential institutional data.
- **Core O*NET Skills**:
  - `2.C.3.a` Information Security & Network Defense (Importance: 95/100) — Firewalls, encryption protocols, access controls, and security auditing.
  - `2.B.3.d` Vulnerability Assessment & Pen Testing (Importance: 88/100) — Identifying and patching security weaknesses across software layers.

### 6. Electrical Engineer (O*NET-SOC 17-2071.00)
- **Role Summary**: Research, design, and develop electrical equipment, power systems, and microelectronics.
- **Core O*NET Skills**:
  - `2.B.3.b` Circuit & Systems Design (Importance: 90/100) — Circuit simulation, schematic capture, and embedded control.
  - `2.C.4.a` Physics (Importance: 88/100) — Electromagnetism, semiconductor physics, and thermodynamics.
  - `2.A.1.b` Calculus & Quantitative Analysis (Importance: 85/100) — Differential equations and signal analysis.

### 7. Business & Systems Analyst (O*NET-SOC 13-1111.00)
- **Role Summary**: Bridge the gap between business objectives and technology implementation.
- **Core O*NET Skills**:
  - `2.C.9.a` Business & Financial Literacy (Importance: 88/100) — Financial metrics, operational workflows, and ROI evaluation.
  - `2.B.3.a` Systems Analysis & Requirements Gathering (Importance: 88/100) — Drafting software specifications, user stories, and acceptance criteria.
  - `2.A.1.d` Written Communication (Importance: 88/100) — Documenting architectural recommendations and stakeholder presentations.
