The National Employment Agency (NEA) Cambodia Skills Gap Survey 2023 reports
that employers in the ICT and business-process-outsourcing sector most
frequently cite shortages in three skill areas: practical software
development (particularly web and mobile), data analysis, and workplace
English communication. Respondents ranked "hands-on project experience" above
GPA as a hiring signal for entry-level software roles.

Employers surveyed in Phnom Penh reported that junior frontend developer
openings (0-2 years experience) most commonly required JavaScript, React or
a comparable component framework, and basic REST API integration. Backend
and full-stack openings additionally required a relational database
(commonly PostgreSQL or MySQL) and familiarity with a cloud hosting
environment.
